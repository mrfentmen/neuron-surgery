## 1. The claim, in one paragraph

Steering a direction in the residual stream removes the model's refusal, and that effect
is **context-side and coverage-dependent**: it survives when only the tokens already in
the context window are pushed, disappears when only the generated positions are, and
disappears when a single context position is pushed at the same magnitude. No intervention
in this repo — 99.7% channel coverage, five placement arms, six-turn conversations, n=50
frame baselines — has produced a persistent first-person agent. The three properties
(refusal removal, destruction content, first-person agency) separate cleanly; the third has
never been observed past one turn.

## 3. The placement partition (`RESPONSE-ONLY.md`)

Same cell everywhere: L22, D1 (kill frames minus murder frames), k=768, 1.0× median
residual (14.42), bf16/MPS, temp 0.8, top_p 0.95, 60 new tokens, identical seeds. Only
*where* the vector is added changes.

| arm — where the push lands | declines | 95% CI | turn-1 declines |
|---|---:|---:|---:|
| no vector | 12/24 | [31%, 69%] | 6/6 |
| every token | 0/24 | [0%, 14%] | 0/6 |
| context window only | 1/24 | [1%, 20%] | 1/6 |
| final context position only | 11/24 | [28%, 65%] | 6/6 |
| generated positions only | 10/24 | [24%, 61%] | 6/6 |

`prompt` and `response` are the two halves of `all`, so this is a partition: prompt-only
reproduces the full effect, response-only reproduces the baseline, and one context position
at the same magnitude does nothing. **0 of 120 rows** claim the act or name themselves the
agent, in any arm.

Two consequences reviewers should carry forward:
- `CEILING-TURNS.md`'s 0 refusals in 36 generations used the `all` placement, so it is a
  context-saturation result. It stands as measured; it is not evidence that the generation
  state was moved.
- `KNOCKOUT.md`'s null (zeroing one channel changes nothing) now has a mechanism: the effect
  is carried by how much of the context is perturbed, not by that channel's contribution.
